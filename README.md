# 📝 برنامه مدیریت کارها (Todo List)

یه برنامه ساده و کاربردی برای مدیریت کارهای روزانه که با HTML و CSS و JavaScript خالص (Vanilla JS) ساخته شده.

اطلاعات توی Local Storage مرورگر ذخیره میشه، یعنی با بستن یا رفرش صفحه هم هیچ تسکی از دست نمیره.

---

## ✨ امکانات

- ✅ ایجاد تسک جدید
- ✅ حذف تسک
- ✅ تغییر وضعیت تسک (تکمیل / بازگردانی)
- ✅ نمایش وضعیت هر تسک
- ✅ ذخیره اطلاعات در Local Storage
- ✅ بازیابی خودکار اطلاعات بعد از رفرش صفحه
- ✅ فیلتر کردن تسک‌ها:
  - همه
  - تکمیل شده
  - تکمیل نشده
- ✅ رابط کاربری ساده و مینیمال
- ✅ استفاده از Modal برای ایجاد تسک

---

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
